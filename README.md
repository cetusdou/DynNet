# DynNet
## Description
This repository contains the DynNet project, which includes various models and data for analysis.


## Installation
To install the necessary dependencies, run:
``` bash
pip install -r requirements.txt
```

## Data

The data directory contains several datasets used for training and testing the models in this project. Below is a brief description of each dataset:

- **MISA_TS**: The MISA_TS dataset is designed for time-series analysis, providing insights into the dynamics of biological systems over time.

- **Synthetic_BoolODE_BF**: This dataset consists of synthetic Boolean ordinary differential equations (ODEs) that serve as a benchmark for testing model performance in simulating biological processes.

- **EMT_TGFb_RV**: This dataset includes data related to epithelial-mesenchymal transition (EMT) under TGF-beta stimulation, which is crucial for understanding cellular development and differentiation processes.

- **Hepatocyte_Development_BF**: This dataset focuses on the development of hepatocytes, the main functional cells of the liver, and includes various biological factors that influence their maturation.



Please ensure to check the individual dataset files for more detailed information and specific usage instructions.


## Usage
For our dataset, pre-trained models are already saved in the repository. Calling these models can yield images consistent with those in our paper. You can find this information in the `/example` directory.
